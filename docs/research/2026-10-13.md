## 3. Techniques for open issues

- #14 (POSIX ACL xattrs in v2 format): the ext4 on-disk form is
  `ext4_acl_header` version 0x0001 (4-byte header), entries short (tag+perm,
  4 bytes) for the first four user/group-obj style entries and long (tag, perm,
  32-bit id) otherwise; xattr name index 2 = `system.posix_acl_access`, 3 =
  `system.posix_acl_default`. The userspace/VFS xattr form is version 0x0002
  with 8-byte entries. So the fix is a v2 -> v1 conversion on write and the
  reverse on read, mirroring kernel `ext4_acl_to_disk`/`ext4_acl_from_disk`.
  Refs: [kernel ext4 attributes doc](https://docs.kernel.org/7.1/_sources/filesystems/ext4/attributes.rst.txt),
  [e2fsprogs ext4_acl.h](https://nest-open-source.googlesource.com/manifest_repos/e2fsprogs/+/a02fb0d50da99e1a4f27487345f0c8fc94ed84f6/lib/ext2fs/ext4_acl.h),
  [fs/ext4/acl.c](https://code.woboq.org/linux/linux/fs/ext4/acl.c.html).
